# daemonless app catalog

The catalog behind [fjord](https://github.com/daemonless/fjord)'s App Store:
every installable daemonless image with icons, versions and install
manifests, as static JSON on GitHub Pages.

- **URL:** `https://catalog.daemonless.io/v1/daemonless/catalog.json`
  (all sources: `https://catalog.daemonless.io/v1/sources.json`)
- **In fjord:** Settings → Catalogs → `https://catalog.daemonless.io/v1/daemonless`

`sources.yaml` says what to scan and how to brand it; `CNAME` and `icon.svg`
ride along into the site. The workflow in `.github/workflows/catalog.yaml`
calls the reusable builder in
[fjord-catalog](https://github.com/daemonless/fjord-catalog) every six hours.
Nothing here is generated by hand.
